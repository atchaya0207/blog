#  My Blog App
A simple and responsive blog application where users can create, publish, and manage blog posts. This project is built to provide a clean and user-friendly blogging experience.

##  Live Demo

 Live Site: https://blog-olive-gamma-57.vercel.app/

##  Features

- Create and publish blog posts
- View all published posts
- Responsive and clean user interface
- Simple and intuitive design
- Fast deployment using Vercel

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Vercel (Deployment)
